# Licences et ressources externes

Les SVG, textures procédurales, fichiers de démonstration et documentation de ce pack ont été générés pour cette livraison. Aucune police tierce ni bibliothèque graphique externe n'est incluse.

La capture de référence déposée par l'utilisateur est conservée dans le dossier `Reference/` uniquement pour guider l'intégration visuelle. Elle n'est pas un élément destiné à être utilisé comme texture dans le plugin.

Si des polices, textures ou assets externes sont ajoutés plus tard, leurs licences doivent être documentées ici avant redistribution.
